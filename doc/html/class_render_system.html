Descripción detallada

Sistema encargado de dibujar las entidades en pantalla.

Este sistema itera sobre las entidades que tienen componentes de renderizado y utiliza la fachada MotorRaylib para dibujarlas en la posición correcta. Se encarga de abrir la ventana y gestionar el bucle de dibujo (BeginDraw/EndDraw).
